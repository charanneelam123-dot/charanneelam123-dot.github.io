# Charan Neelam — AI engineering portfolio

Live website: https://charanneelam123-dot.github.io/

Static portfolio with 16 project repositories, four application demos, three walkthroughs, six case studies, and a reproducible local Llama evaluation.

GitHub Pages serves the root of the `main` branch. `.nojekyll` keeps static assets unchanged. No API credentials or backend services are required to serve this website.

The site source is maintained in the local `charan-ai-portfolio/dist` directory. Copy its complete contents here and push an update to publish a new version.
